# Contributing

This is a curated technical demonstrator, not a customer-work repository. Suggestions are welcome when they improve reproducibility, security, accessibility, or technical clarity without adding client data or speculative features.

Run `npm ci`, `npm run check`, `npm test`, and `npm run build` before a pull request. Do not contribute credentials, personal data, customer context, production URLs, raw integrations, or unverified claims. Follow [SECURITY.md](SECURITY.md) for sensitive concerns.
